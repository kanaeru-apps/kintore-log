# App Review 実機録画・再提出チェックリスト

AppleのGuideline 2.1「Information Needed」への回答用。録画と記載内容は、必ず実際に審査へ出す同一ビルドで確認する。

## 1. 録画前の実機確認

- [ ] Codemagic/TestFlightで、審査に出すビルドを実機へインストールした
- [ ] 設定画面の表示バージョンとApp Store Connectのビルド番号を記録した
- [ ] 「設定 > 一般 > 情報」でiPhoneモデルとiOSバージョンを確認した
- [ ] アプリ起動時にクラッシュせず、全タブを開ける
- [ ] 筋トレ記録を新規作成・編集・削除できる
- [ ] 有酸素運動を記録できる
- [ ] 履歴カレンダーとグラフに記録が反映される
- [ ] RM計算機が動作する
- [ ] タイマーが前面・バックグラウンド・画面ロック中に完了する
- [ ] 通知バナー・音・設定どおりの振動を確認した
- [ ] CSVの書き出しと読み込みを確認した
- [ ] ご意見フォームを送信しない限り、記録データが外部送信されない仕様を再確認した
- [ ] App Store Connectの「Appのプライバシー」が、任意のご意見フォーム（本文・任意メール・アプリバージョン）と一致している

未確認の端末・OSは審査Notesへ記載しない。

## 2. 画面録画の流れ

1. iPhoneのホーム画面から録画を開始する。
2. 筋トレLogをタップして起動する。
3. 「記録」で筋トレ種目を追加し、重量・回数を入力して保存する。
4. 「履歴」で保存した日と内容を表示する。
5. 「グラフ」で推定1RMまたはトレーニング量を表示する。
6. 「計算機」で重量と回数を選び、推定1RMを表示する。
7. 「タイマー」で短い時間を設定して開始する。
8. 新規インストール時は通知の用途が分かる画面から通知を許可する。
9. アプリをバックグラウンドへ移すか画面をロックし、終了通知が届くところまで映す。
10. 「設定」でアカウントや課金がないこと、データ管理（CSV）とアプリのバージョンを映す。
11. ホーム画面へ戻り、録画を終了する。

個人の実データやメールアドレスは映さず、審査用のサンプル記録を使う。

## 3. App Store Connectへの記載・添付

- [ ] 録画ファイルをResolution CenterのAppleへの返信に添付した
- [ ] `store/app-review-notes-en.txt` の角括弧プレースホルダーを実測値へ置き換えた
- [ ] App Review InformationのNotes欄にも、置換済みの内容を保存した
- [ ] 添付動画名、端末モデル、iOS、ビルド番号が相互に一致している
- [ ] Appleの7項目すべてに回答している
- [ ] 新しいビルドを出す場合は、そのビルドを選択した状態を確認した

返信・再提出は、録画の添付と実測値の入力が終わってから行う。
